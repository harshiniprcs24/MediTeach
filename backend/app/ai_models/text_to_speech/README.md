# Text-to-Speech Models

Converts AI responses to audio for patients with low literacy.

## Options

| Provider | Setup |
|---|---|
| gTTS (Google TTS) | `pip install gTTS` – works offline for short texts |
| OpenAI TTS | Set `OPENAI_API_KEY` in `.env` |
| Coqui TTS (local) | `pip install TTS`, place model weights here |

## Supported Languages
- English (en)
- Tamil (ta)
- Hindi (hi)
- Telugu (te)
